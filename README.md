# Android Device Tree for Xiaomi Redmi A4 / POCO C75 5G (warm)

The Xiaomi Redmi A4 / POCO C75 5G (codenamed *"warm"*) is a budget 5G smartphone from Xiaomi, announced in late 2024. It is notable for being the global debut device for the Qualcomm Snapdragon 4s Gen 2 platform.

## Device Specifications

| Feature            | Specification                                  |
|--------------------|------------------------------------------------|
| SoC                | Qualcomm SM4635 Snapdragon 4s Gen 2 (4nm)      |
| CPU                | Octa-core (2x2.0 GHz Cortex-A78 & 6x1.8 GHz)   |
| GPU                | Adreno 611                                     |
| Memory             | 4GB / 6GB LPDDR4X                              |
| Shipped OS         | Android 14 (Xiaomi HyperOS)                   |
| Storage            | 64GB / 128GB UFS 2.2                           |
| Battery            | 5160 mAh (18W Fast Charging)                   |
| Display            | 6.88" IPS LCD, 120Hz (720 x 1640)              |
| Camera (Main)      | 50 MP, f/1.8 (Wide) + Auxiliary lens           |
| Camera (Front)     | 5 MP / 13 MP (depending on region)             |

## Repository Info
- **Architecture:** arm64
